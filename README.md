# 🎮 BGHQ — Free Fire Point Table Generator

> **Professional Point Table Generator for Free Fire Tournaments**  
> Built with a neon cyberpunk aesthetic. Fast, customizable, and mobile responsive.

---

## 🖥️ Live Preview

A fully browser-based web app — no backend required. Just open `index.html` in any modern browser.

---

## ✨ Features

- 🔵 **Neon Cyberpunk UI** — Dark theme with glowing neon accents
- 📊 **Point Table Generator** — Quickly generate and display FF tournament standings
- 👤 **Admin Panel** — Manage tournament data via `admin.html`
- 📋 **Dashboard** — View live standings and player stats in `dashboard.html`
- 🎬 **Hero Video Background** — Immersive full-screen video (`bgfile.mp4`)
- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet, and desktop
- 🔗 **Social Panel** — Instagram, Discord, WhatsApp, Twitter, and Facebook links built-in

## 🚀 Getting Started

Since this is a pure HTML/CSS/JS project, there's no build step required.

### Option 1 — Open Directly
```
Double-click index.html in your file explorer
```

### Option 2 — Serve Locally (recommended for video playback)
```bash
# Using VS Code Live Server extension
Right-click index.html → "Open with Live Server"

# OR using Python
python -m http.server 8080
# Then visit http://localhost:8080
```
